# About

This repository contains packages for [Maestro](https://github.com/maestro-os/maestro)'s default distribution.
Those packages are meant to be built and distributed using [Blimp](https://github.com/maestro-os/blimp).

Each directory contains a package, which can be built using `blimp-builder`.
